## Edit and rebuild

Edit `story.js` for narration and timing; `film.js` for motion design; `player.css` for the rehearsal UI. Run:

```powershell
node docs/video/animation/prepare.mjs
node docs/video/animation/render.mjs --preview
node docs/video/animation/render.mjs
node docs/video/animation/serve.mjs
```

Rendering uses the desktop's already bundled Playwright and installed Chrome, referenced by external paths in `render.mjs`. Override them with `POLARIS_PLAYWRIGHT` (path to Playwright's package.json) and `POLARIS_CHROME` (browser executable). Neither is an app dependency. The runtime preview and AVC muxer add no npm dependencies, and the application is unchanged. No model or network call is used during preparation or rendering.

The optional preview server opens at `http://127.0.0.1:4174/animation/`. It serves only this video folder and supports byte ranges for MP4 seeking. To repeat playback verification, use `OFFLINE=1`, remove `OPENAI_API_KEY` from the process environment, and run `node docs/video/animation/verify.mjs`.

The encoder uses browser WebCodecs. The local muxer writes one constant-rate, realtime H.264 track with the MP4 metadata before the video data. It rejects missing decoder configuration and reordered samples. The frame audit checks text against a 60-pixel safe frame at half-second intervals. The full-resolution source files are editable even if a different environment lacks encoding support.

For motion sensitivity, the rehearsal player starts paused and uses settled compositions when reduced motion is requested. The exported video retains its authored motion. A desktop or landscape display is recommended for reading the 16:9 video; the playback UI itself fits smaller viewports.
